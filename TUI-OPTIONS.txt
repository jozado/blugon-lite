OPCIÓN 1: whiptail / dialog
================================================================================

DESCRIPCIÓN:
  Herramientas de sistema para interfaces de texto tipo "instalador Debian"

INSTALACIÓN:
  Sistema (Debian/Ubuntu):
    sudo apt install whiptail   # o dialog
  
  Python: NO requiere (se usa desde bash)

DEPENDENCIAS:
  - whiptail o dialog (ya incluido en la mayoría de sistemas Debian)
  - bash
  - Peso: ~100KB

EJEMPLO DE CÓDIGO:
  #!/bin/bash
  
  whiptail --title "blugon-lite" --msgbox "Bienvenido" 8 40
  
  MENU=$(whiptail --title "Menú Principal" --menu "Selecciona:" 15 60 7 \
      "1" "Ver estado actual" \
      "2" "Editar horarios" \
      "3" "Agregar horario" \
      3>&1 1>&2 2>&3)
  
  case $MENU in
      1) echo "Mostrando estado..." ;;
      2) echo "Editando..." ;;
  esac

VENTAJAS:
  ✅ Cero dependencias Python
  ✅ Ya instalado en Debian/Ubuntu por defecto
  ✅ Ultra-ligero
  ✅ Fácil de mantener (solo bash)
  ✅ Familiar para usuarios de sistemas Unix
  ✅ No requiere pip ni virtualenv

DESVENTAJAS:
  ❌ Interfaz básica (tipo instalador)
  ❌ No es interactivo en tiempo real
  ❌ Limitado a menús simples
  ❌ No se puede hacer algo tipo "htop"
  ❌ Bash se vuelve complejo para lógica avanzada

COMPLEJIDAD:
  ★☆☆☆☆ (Muy fácil - solo bash)

IDEAL PARA:
  - Proyectos ultra-minimalistas
  - Sin dependencias externas
  - Menús simples de configuración
  - Scripts de instalación

OPCIÓN 2: urwid
================================================================================

DESCRIPCIÓN:
  Librería Python para TUIs interactivas tipo "htop", "ncmpcpp", "ranger"

INSTALACIÓN:
  Python (pip):
    pip install urwid
  
  Sistema (Debian/Ubuntu):
    sudo apt install python3-urwid

DEPENDENCIAS:
  - Python 3
  - urwid (~200KB)
  - Peso total: ~500KB con dependencias

EJEMPLO DE CÓDIGO:
  #!/usr/bin/env python3
  import urwid
  
  # Widgets
  text = urwid.Text("blugon-lite Configuration")
  button = urwid.Button("Save")
  
  # Layout
  layout = urwid.Pile([text, button])
  
  # Loop principal
  loop = urwid.MainLoop(layout)
  loop.run()

VENTAJAS:
  ✅ Interfaz muy interactiva (tipo htop)
  ✅ Navegación con teclado (flechas, enter, etc.)
  ✅ Widgets reutilizables (listas, botones, inputs)
  ✅ Actualización en tiempo real
  ✅ Colores y estilos
  ✅ Maduro y estable (desde 2009)
  ✅ Buena documentación
  ✅ Relativamente ligero

DESVENTAJAS:
  ❌ Requiere instalación con pip (o apt)
  ❌ Curva de aprendizaje media
  ❌ Más código que whiptail
  ❌ Necesita entender eventos y loops

COMPLEJIDAD:
  ★★☆☆☆ (Media - requiere aprender urwid)

IDEAL PARA:
  - Aplicaciones interactivas completas
  - Navegación tipo "explorador de archivos"
  - Actualización en tiempo real
  - Proyectos Python existentes

OPCIÓN 3: textual (Rich)
================================================================================

DESCRIPCIÓN:
  Framework moderno para TUIs con estilo "aplicación web"

INSTALACIÓN:
  Python (pip):
    pip install textual

DEPENDENCIAS:
  - Python 3.7+
  - textual + rich (~1MB total)
  - Requiere terminal con soporte para colores/unicode

EJEMPLO DE CÓDIGO:
  from textual.app import App
  from textual.widgets import Header, Footer, Static
  
  class MyApp(App):
      def compose(self):
          yield Header()
          yield Static("Hello World")
          yield Footer()
  
  MyApp().run()

VENTAJAS:
  ✅ Muy moderno y bonito
  ✅ Estilo CSS-like para diseño
  ✅ Fácil de aprender si vienes de web
  ✅ Actualización reactiva
  ✅ Widgets modernos
  ✅ Buena documentación y ejemplos

DESVENTAJAS:
  ❌ Más pesado (~1MB dependencies)
  ❌ Más nuevo (menos maduro que urwid)
  ❌ Requiere terminal moderno
  ❌ Overkill para algo simple

COMPLEJIDAD:
  ★★☆☆☆ (Media - fácil si conoces web)

IDEAL PARA:
  - Aplicaciones modernas
  - Equipos que vienen de desarrollo web
  - Proyectos que priorizan UX
  - Terminales modernos

OPCIÓN 4: blessed + código propio
================================================================================

DESCRIPCIÓN:
  Wrapper moderno para curses, control total pero más código manual

INSTALACIÓN:
  Python (pip):
    pip install blessed

DEPENDENCIAS:
  - Python 3
  - blessed (~100KB)
  - Peso total: ~300KB

EJEMPLO DE CÓDIGO:
  #!/usr/bin/env python3
  from blessed import Terminal
  
  term = Terminal()
  
  with term.fullscreen(), term.cbreak():
      print(term.move_y(1) + term.bold("blugon-lite"))
      while True:
          inp = term.inkey()
          if inp == 'q':
              break
          elif inp.code == term.KEY_DOWN:
              # Mover selección abajo
              pass

VENTAJAS:
  ✅ Muy ligero
  ✅ Control total sobre la terminal
  ✅ Más simple que urwid para cosas básicas
  ✅ Bueno para aprender cómo funciona TUI

DESVENTAJAS:
  ❌ Mucho código manual (no hay widgets)
  ❌ Tienes que construir todo desde cero
  ❌ Más propenso a bugs
  ❌ Menos reusable

COMPLEJIDAD:
  ★★★☆☆ (Alta - todo manual)

IDEAL PARA:
  - TUIs muy específicas y simples
  - Aprender cómo funcionan las TUIs
  - Control total sobre cada caracter
  - Proyectos educativos

OPCIÓN 5: curses (stdlib)
================================================================================

DESCRIPCIÓN:
  Librería estándar de Python para TUIs

INSTALACIÓN:
  Python (incluido en stdlib):
    import curses  # ¡Ya está instalado!

DEPENDENCIAS:
  - Python 3 (curses incluido)
  - Peso: 0KB adicional

EJEMPLO DE CÓDIGO:
  #!/usr/bin/env python3
  import curses
  
  def main(stdscr):
      curses.curs_set(0)
      stdscr.addstr(0, 0, "blugon-lite")
      stdscr.refresh()
      stdscr.getch()
  
  curses.wrapper(main)

VENTAJAS:
  ✅ Cero dependencias (incluido en Python)
  ✅ Muy ligero
  ✅ Poderoso y flexible
  ✅ Estándar de la industria

DESVENTAJAS:
  ❌ API de bajo nivel (más código)
  ❌ Menos intuitivo que urwid/textual
  ❌ Más propenso a errores
  ❌ Documentación menos amigable

COMPLEJIDAD:
  ★★★☆☆ (Alta - API de bajo nivel)

IDEAL PARA:
  - Cero dependencias externas
  - Proyectos que ya usan curses
  - Cuando el tamaño importa mucho
  - Desarrolladores experimentados

  - Desarrollo: 200-300 líneas de Python
  - Tiempo: 4-6 horas
  - Mantenimiento: Bajo

ALTERNATIVA SI QUIERES CERO DEPS: whiptail

POR QUÉ:
  1. Ya instalado en todos los sistemas Debian/Ubuntu
  2. Cero dependencias adicionales
  3. Suficiente para menús básicos de configuración

PERO:
  - No será tan interactivo

NOTAS ADICIONALES
================================================================================

SOBRE INSTALACIÓN DE urwid:
───────────────────────────
NO es complicado. El usuario tiene dos opciones:

1. DESDE REPOSITORIOS (recomendado):
   sudo apt install python3-urwid
   
   Ventaja: Se actualiza con el sistema
   Desventaja: Versión puede ser antigua

2. DESDE PIP:
   pip install urwid
   
   Ventaja: Última versión
   Desventaja: Mezcla sistema/pip

3. DESDE .deb (MEJOR OPCIÓN):
   El paquete blugon-lite.deb incluye:
   Depends: python3 (>= 3.6), python3-urwid
   
   Al instalar:
   sudo dpkg -i blugon-lite.deb
   sudo apt-get install -f  # Instala dependencias automáticamente
   
   ¡El usuario no necesita saber sobre urwid!

COMPARACIÓN DE COMPLEJIDAD:
───────────────────────────
whiptail (bash):
  - 50-100 líneas de bash
  - Menús simples
  - Sin actualización en tiempo real
  - Difícil de extender

urwid (Python):
  - 200-300 líneas de Python
  - Interfaz completa tipo htop
  - Tiempo real
  - Fácil de extender

CONCLUSIÓN:
───────────
urwid es la mejor opción para blugon-lite porque:
  1. Mantiene el espíritu minimalista pero permite UX decente
  2. Se empaca fácilmente en .deb con dependencias
  3. El usuario final solo hace: sudo dpkg -i
  4. Permite crecimiento futuro sin cambiar de librería
