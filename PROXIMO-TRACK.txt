DESCRIPCIÓN DEL TRACK
================================================================================

Crear un paquete .deb instalable para blugon-lite que incluya:
1. Script auto-configurable con fallback automático
2. TUI (Text User Interface) con urwid para configuración interactiva
3. Sistema de paquetes Debian con postinst para configuración automática
4. Múltiples configuraciones predefinidas

Objetivo final: El usuario puede instalar con `sudo dpkg -i blugon-lite.deb`
y usar inmediatamente sin configuración manual.

================================================================================
CARACTERÍSTICAS A IMPLEMENTAR
================================================================================

1. AUTO-CONFIGURACIÓN (Prioridad: ALTA)
────────────────────────────────────────
El script buscará configuración en este orden:
  1. ~/.config/blugon/gamma (config del usuario)
  2. /usr/share/blugon-lite/configs/evening/gamma (sistema)
  3. Fallback hardcodeado en el script

Archivos a modificar:
  - blugon-lite.py (función read_gamma)

2. PAQUETE .DEB (Prioridad: ALTA)
────────────────────────────────────────
Estructura debian/ completa para construir paquete instalable

Archivos a crear:
  - debian/control (metadatos, dependencias)
  - debian/postinst (script post-instalación)
  - debian/prerm (script pre-remoción)
  - debian/conffiles (archivos de configuración)
  - debian/blugon-lite.docs (documentación)
  - debian/blugon-lite.install (archivos a instalar)
  - debian/blugon-lite.maintscript (migraciones)

Dependencias:
  - python3 (>= 3.6)
  - python3-urwid (para el TUI)
  - libx11-6, libxrandr2 (para backend scg)

3. TUI CON URWID (Prioridad: ALTA)
────────────────────────────────────────
Interfaz de texto interactiva tipo htop para configurar blugon-lite

Funcionalidades:
  - Ver estado actual (gamma, próxima transición)
  - Ver/editar horarios configurados
  - Agregar nuevos horarios
  - Eliminar horarios existentes
  - Guardar configuración
  - Iniciar/detener daemon
  - Salir con confirmación si hay cambios sin guardar

Archivos a crear:
  - blugon-lite-tui (wrapper ejecutable)
  - blugon-lite-tui.py (código fuente del TUI)

4. CONFIGURACIONES PREDEFINIDAS (Prioridad: MEDIA)
────────────────────────────────────────
Múltiples perfiles de configuración para diferentes casos de uso

Archivos a crear:

  - configs/student/gamma (estudiante, horarios extendidos)
  - configs/night-owl/gamma (nocturno)
  - configs/minimal/gamma (solo 3 puntos)

5. DOCUMENTACIÓN MEJORADA (Prioridad: ALTA)

README actualizado con:
  - Instrucciones de instalación del .deb

  - Ejemplos de diferentes casos de uso

Archivos a modificar:

  - No incluir en requirements.txt (es dependencia del sistema)
  - El .deb lo maneja via Depends: python3-urwid
  - Usuario no necesita instalar manualmente

SOBRE POSTINST:
  - Debe ser idempotente (puede ejecutarse múltiples veces)
  - No debe sobrescribir config del usuario si ya existe
  - Debe manejar actualizaciones desde versiones previas

SOBRE EL TUI:
  - Mantener simple pero funcional
  - No sobrecargar con características innecesarias
  - Priorizar usabilidad sobre features

SOBRE COMPATIBILIDAD:
  - Mantener compatibilidad con configs de blugon original
  - No romper API de línea de comandos existente
  - blugon-lite.py debe seguir funcionando sin el TUI
